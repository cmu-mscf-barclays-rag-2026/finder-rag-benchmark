# Advanced Retrieval for Financial Applications

A 12-week CMU MSCF–Barclays research project exploring how to retrieve reliable,
relevant evidence for financial search and retrieval-augmented generation (RAG).

Our goal is a configurable retrieval framework for financial applications. We
investigate datasets, document processing, retrieval methods, query enhancement,
and evaluation, comparing evidence quality, grounding, latency and cost.
Research directions, datasets and individual assignments evolve each week.
